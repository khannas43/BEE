# BEE portal: hand-over note, 19 October 2026

For whoever takes over the code. Read this, then `README.md`, then `docs/demo/DEMO_RUNBOOK_BEE_OFFICIALS.md`. This note supersedes `HANDOVER_2026-10-17.md` for the state of the code and the demonstration; that note stays as history (its paths and role names are older).

## 1. What this is
A local demonstration of the BEE Standards and Labelling portal, shown from one laptop to BEE officials (about 30 minutes). PostgreSQL, Keycloak, a Spring API (port 8090) and a Next.js portal (port 3100). All data is synthetic. Simulated and labelled on screen: the Fabric ledger, the payment gateway, e-mail/SMS/OTP, KYC and the AI helpers. No tunnel (ngrok) is open and none should be.
