# WP05.1b — Model application draft create and edit

Status: **implemented locally; re-review corrections applied, awaiting acceptance.** WP05.1 and WP05 remain open; work-package count stays **1/11**. Branch `wp05.1b-model-drafts` from reviewed WP05.1a tip `5e157df`.

Manufacturers and authorised agencies can **create** and **edit draft** model applications through Spring, the Next.js BFF, the runtime sidebar, the model dashboard (Edit on owned drafts), and the new/edit form. New rows store filing organisation (`organisation_id`), principal organisation and brand id; seeded rows without a safe brand link keep null brand columns. Submit, fees, rating, approval and history stay denied. None of the 540 matrix proposals is granted.

## API (contract 0.4.1)

| Operation | Route | Notes |
| --- | --- | --- |
| GET eligible brands | Spring `/api/model-applications/eligible-brands`, BFF `/api/runtime/model-applications/eligible-brands` | Scoped list for the form |
| POST create draft | Spring POST `/api/model-applications` | Requires `Idempotency-Key`; stores brand linkage |
| PATCH edit draft | Spring PATCH `/api/model-applications/{id}` | Draft state only; optimistic `version` |

Idempotency store: Flyway **V7** (`idempotency_record`). Reference allocation: Flyway **V8** (`model_application_reference_allocator`, row-locked `next_value`). Replay returns `Idempotency-Replayed: true`. Conflicts: `version_conflict`, `idempotency_key_conflict`, `idempotency_in_progress`.

## Review blockers — addressed (1 October 2026)

1. **Portal edit path.** Dashboard list and detail expose **Edit** for `draft` rows; form supports `?edit={id}` with PATCH and returned `version`. Runtime nav includes **New model application**.
2. **Runtime navigation.** `/app/model-label/new-model-application` is a `RUNTIME_ROUTES` entry (Spring roles only, truthful `implemented` chrome, preview bypass like the dashboard).
3. **Baseline-preserving live writes.** `local:model-drafts` uses disposable rows only, deletes them and twin idempotency rows in `finally`, asserts `model_application` snapshot unchanged, runs **twice**, then `local:check` (four seeded applications unchanged).
4. **Reference allocator.** V8 table + locked increment; `ModelApplicationDraftDatabaseTest` proves concurrent allocations are distinct.
5. **Idempotency retry.** `DraftIdempotencyGate` reuses one key per payload until success; live check retries after a successful create with the same key and asserts one row.

## Re-review corrections (1 October 2026)

1. **Allocator rewind on seed — fixed.** Seed upsert uses `GREATEST(model_application_reference_allocator.next_value, EXCLUDED.next_value)` (generated from `local/generate-fixtures.cjs`). `ModelApplicationDraftDatabaseTest.seedReplayDoesNotRewindAllocatorAfterDraftRemoved` allocates, inserts and deletes a disposable draft, re-runs `seed.sql`, and proves the next reference never repeats.
2. **Unsafe legacy edit default — fixed.** Edit form does not auto-select a brand when `brandId` is absent on the loaded draft; PATCH omits `brandId` until the user chooses one. Spring `legacyBrandId` links only on a unique eligible name match; otherwise `422 validation_failed`. Live checks cover unique reconcile (PATCH without `brandId`), mismatched legacy name with two eligible brands (422, row unchanged), and explicit `brandId` after ambiguity.
