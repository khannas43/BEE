# WP04.2b-3 — The register feeds the model flow (R1)

**Status:** Evidence added on branch `wp04-registration-3` (14 October 2026). No backend, contract or migration change was needed. Accepted as part of the WP04 package (14 October 2026, [WP04_PACKAGE_REVIEW.md](WP04_PACKAGE_REVIEW.md)).

**Provisional local rules, not BEE rules.**

## What was found

The plan expected two changes: consume brand authorisation at model submit, and replace the free-text `model_application.brand_name` with a brand id. Both were already in place from WP04.2a and WP05.1b/c:

- A model application is created with a **`brandId`** (create refuses a body without one); an edit keeps the draft's brand or takes a new `brandId`, and a legacy draft without one is linked only when its name matches exactly one eligible brand. `brand_name` is written from the brand row, never from the request.
- Draft create, edit and submit all call `ModelDraftPolicy.brandForFiling` against `brand` and `agency_authorisation` (active brand, owner or an agency whose authorisation covers today, half-open period). The refusal is `403 brand_not_permitted`.
- `eligible-brands` lists exactly the brands the caller may file on.

So the registration workflow of WP04.2b-1 and 2b-2 needed no change in the model flow: a brand or an authorisation that approval writes is used by it immediately.

## What this package adds

Live proof of the whole chain, in `registration-review-browser-check.cjs` (section 4, 18 more checks over the two runs; the script is now 122 checks, `npm run local:registration-review`):

| Step | Result |
| --- | --- |
| A brand is approved through the workflow | its owner is offered it and files a draft on it (201) |
| An agency with no authorisation files on it | 403 `brand_not_permitted` |
| An agency authorisation approved to start tomorrow | 403 `brand_not_permitted` today |
| An agency authorisation approved from today | the brand is offered to the agency and a draft is filed (201) |
| That authorisation revoked | 403 `brand_not_permitted`, and the brand is no longer offered |

Every model draft, registration, brand and authorisation the check makes is removed.
