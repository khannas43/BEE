# WP05.1c — Submit draft → fee_due (S1 / A1)

**Status:** implemented locally; WP05 not accepted.

## Scope

- `GET` / `POST /api/model-applications/{id}/submit` (Spring) and `/api/runtime/model-applications/{id}/submit` (BFF).
- Filing manufacturer or authorised agency on **own** draft only; brand/agency recheck from Spring DB at submit time.
- Category, performance-test standard and `new_model` fee rule must exist for submission date; missing rule → `422 rule_not_available` (fail closed).
- Fee snapshot at submit: amount, currency, rule key/version, verification, provenance; ₹24,000 RAC seed labelled **local demo** (`localDemoFee`, `label`), not BEE-approved.
- Atomic `draft` → `fee_due`, version increment, one submission event + one fee row per application; idempotent POST replay.
- UI: review/confirm provisional fee on the real draft screen; dashboard refresh via Spring list/read after submit.
