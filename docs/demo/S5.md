# S5 MIS dashboard (local demonstration, not a BEE report)

- **Real:** every figure is a SQL aggregate over the live tables, computed on each call (`gov.bee.api.demo.mis`, module `mis`, GET only; a POST answers `validation_failed`). Each response carries `asOf`, `dataVersion` (12 hex of a hash of the source row counts: same data, same value), `sources` and `demonstration: true`. Panels: `mis/summary`, `applications`, `finance`, `production`, `certificates`; `mis/export?panel=<name>` returns CSV text in `csv`. Optional `from`/`to` (yyyy-mm-dd, at most 36 months) apply to the monthly series.
- **Roles:** programme, director, secretary, admin, auditor see every panel; finance sees only `finance` (and its export); all others get `role_not_permitted`. Migration V61 only grants SELECT to `bee_runtime`.
- **Not yet available parts:** `payment`, `production_*`, `ledger_tx`, `qr_*` are read only when the table exists, the runtime login may read it and the columns used are present; otherwise the panel lists the part as "not available yet". (Slices S1 to S4 must give `bee_runtime` SELECT on their tables.)
- **Synthetic history:** `local/seed/demo/s5_mis.sql` (apply after `local/seed/seed.sql`, idempotent) adds 40 model applications over 12 months in three synthetic organisations SYNTH-MFG-1..3 (references SYN-MA-nnnn, receipts SYN-RCPT-*, certificates BEE/RAC/<year>/9nnnn) and 9 registrations. It is NOT in the shared seed, so no existing seeded-row count changes; apply it for the demo only.
- **Demo (bee.director):** open MIS dashboard; read the cards and the as-of / data version line; switch tabs; narrow the date range; download the CSV; open the table under any chart; sign in as bee.finance to see only the Finance tab.
- **Screen:** `components/app/demo/MisDemo.tsx` (inline SVG and CSS bars, a table under every chart, role="alert" errors, role="status" loading).
